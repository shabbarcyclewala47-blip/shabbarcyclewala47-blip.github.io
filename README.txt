# Shabbar Cyclewala — Portfolio

Animated single-page portfolio (HTML + CSS + GSAP).

## Preview
Open index.html in a browser. Your photo and all three project images are embedded inside index.html, so they show even if the file is opened on its own.
Internet is needed for Google Fonts and GSAP (animations). Without it the page still shows everything, just without motion.

## Publish free with GitHub Pages
1. Create a public repository (e.g. shabbarcyclewala47-blip.github.io).
2. Upload index.html and the assets folder to the repository root.
3. Settings -> Pages -> Deploy from a branch -> main / (root) -> Save.

## Files
- index.html — complete website
- assets/Shabbar-Cyclewala-Resume.pdf — resume linked from the site (keep this folder next to index.html)
- assets/*.jpg — the optimized photo and project images (already embedded in index.html; kept for reuse)
